# BidetFit Definition of Done

A work item is Done only when all applicable conditions are true:

- [ ] The implementation, research, decision, design, or operational action is complete.
- [ ] Every acceptance criterion is met or explicitly waived by the authorized owner.
- [ ] Required tests pass; failed, skipped, unavailable, and waived checks remain distinct.
- [ ] Verification evidence is linked to an exact artifact, commit, workflow run, URL, or approval.
- [ ] Canonical repository docs are updated only where facts changed.
- [ ] Prompt IDs, outputs, decisions, bugs, risks, assumptions, and diary entries are updated where relevant.
- [ ] Estimated and actual dates and hours are recorded; unknown historical actuals are marked honestly.
- [ ] Jira status, worklog, evidence, dependencies, and discussion are synchronized.
- [ ] Notion project, task, doc, and decision mirrors are synchronized.
- [ ] Privacy, security, legal, affiliate, communication, and financial gates are satisfied.
- [ ] Production work is deployed, smoke-tested, observable, and rollback-ready.
- [ ] The handoff states what changed, what failed, evidence, known limitations, and next work.

Never use Done to mean “code written,” “draft produced,” “probably works,” or “planned.” If verification or synchronization is missing, the item remains In Progress or Blocked.
